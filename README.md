# COMP 360 Project 1 LearnCompiler 

	COMP 360-01 Programming Languages Fall 2026
	
Project 1

Due Date: October 3

Objective: Learn programming language implementation systems. Practice conduction syntax analysis on given program components.

Assignment: Language implementation systems must input a file, identify substrings, and find all syntax errors, regardless of the specific implementation approach. For an input program a lexical analyzer will break a file into lexemes and tokens. A parser will find all syntax errors. For each error the parser will produce an appropriate diagnostic message, and recover quickly.

For the  LearnCompiler Function defined as follows: 
choose a programming language (C, C++, or Java) that you are familiar with, to implement a lexical analyzer and a top-down parser. The lexical analyzer will read the Sample program and generate lexemes with token types. The parser must use the recursive-descent parsing to implement the syntax analysis. The project must implement the following functions:

- Input the Sample Program. Each time read one Sample Program.
- Use the Lexical Analyzer to generate lexemes and tokens, and display them.
- Use the recursive-descent parser to check the syntax of the Sample Program.
- If the Sample Program is generated by the LearnCompiler Function display “The Sample Program is generated by the BNF grammar”, otherwise display “The Sample Program cannot be generated by the LearnCompiler BNF Grammar” and identify the first syntax error.
